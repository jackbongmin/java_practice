# 1일차 1교시 실습 — 프로그램과 자바 코드 첫 만남

## 이번 시간에 할 일

- 자바 소스 코드가 담기는 `.java` 파일을 **처음으로 직접 열어 봅니다.**
- 파일 이름 · 클래스 이름 · 중괄호 범위 · 값을 적을 자리를 코드에서 **찾아 표시합니다.**
- 이 파일에 **실행을 시작하는 명령이 없다**는 것을 스스로 확인하고, 그 질문을 2교시로 가져갑니다.

## 실습 파일

| 파일 | 역할 |
|------|------|
| `chapter03/User.java` | 사용자 정보를 적을 자리만 선언한 클래스 |

> 이번 시간에는 **컴파일도 실행도 하지 않습니다.** 코드를 고치지도 않습니다.
> 열고, 찾고, 줄 번호를 적는 것이 전부입니다. 편집기에서 줄 번호 표시를 켜 두세요.
> `String`·`int`처럼 아직 배우지 않은 낱말이 나오면 외우려 하지 말고 그대로 옮겨 적으면 됩니다.

## 미션

### 1-1. `.java` 파일을 연다
`chapter03/User.java`를 편집기로 엽니다.

- 파일 이름은 무엇인가요? 확장자는 무엇인가요?
- 화면에 보이는 것이 **사람이 읽을 수 있는 글**인지, 사람이 알아볼 수 없는 기계용 형식인지 한 줄로 적습니다.

### 1-2. 파일명과 클래스명을 대조한다
`public class`로 시작하는 줄을 찾습니다.

```java
public class User {
```

- 이 줄은 **몇 번째 줄**인가요? 클래스 이름은 무엇인가요?
- 확장자를 뺀 파일명(`User`)과 클래스 이름이 **대소문자까지** 같은지 대조해 적습니다.

### 1-3. 중괄호로 범위를 표시한다
`public class User` 뒤의 여는 중괄호 `{`와, 짝이 되는 닫는 중괄호 `}`를 찾습니다.

- 여는 줄 번호와 닫는 줄 번호를 적습니다.
- 그 **사이**가 User라는 코드 묶음의 범위입니다. 편집기에서 두 줄을 선택해 범위를 눈으로 확인하세요.

### 1-4. 값을 적을 자리를 찾는다
중괄호 **안쪽**에 있는 줄들을 봅니다.

```java
    String name;
    String phoneNumber;
    int age;
```

이름과 앞에 붙은 표기를 표로 옮깁니다. **세 개**가 나오면 맞습니다.

| 이름 | 앞에 붙은 표기 | 무엇을 적는 자리인가 |
|------|--------------|-------------------|
| | | |

→ `String`과 `int`가 정확히 무엇인지는 뒤에서 배웁니다. 지금은 **"값의 종류를 표시한 것"** 으로만 적습니다.

### 1-5. 실행 명령이 있는지 확인한다
화면에 결과를 보여 주는 줄은 자바에서 이렇게 생겼습니다.

```java
System.out.println(name);
```

`User.java` 안에서 `System.out.println`을 검색합니다.

- **검색 건수**를 적습니다.
- 이 파일에 **실행을 시작하는 명령이 있는지 없는지** 판정하고, 그렇게 판정한 근거를 한 줄로 씁니다.

### 1-6. 프로그램의 흐름으로 정리한다
프로그램이 하는 일을 **입력 → 처리 → 출력** 세 단계로 한 문장씩 적습니다.

그 위에 1-4(값의 자리 3개)와 1-5(검색 건수)의 결과를 놓고 답합니다.

- **이 파일만으로 프로그램이 돌아갈까요?** 답과 이유를 한 줄로 씁니다.
- 그렇다면 사람이 읽는 `User.java`를 컴퓨터가 실행할 수 있는 형태로 **누가** 바꿔 줄까요? 지금은 답을 몰라도 됩니다. **질문만 적어 두고 2교시에 확인합니다.**

## 스스로 점검

- `User.java`에서 파일 이름 · 클래스 이름 · 값의 자리를 각각 **손가락으로 짚어** 말할 수 있다.
- 파일명과 공개 클래스 이름이 같아야 한다는 규칙을 이 파일에서 확인했다.
- 값을 적을 자리는 **3개**, 실행 명령 검색 결과는 **0건**이라고 수로 말할 수 있다.
- 처음 보는 코드를 파일 이름 → 코드 묶음 → 안쪽 내용 순서로 좁혀 읽는 방법을 안다.

## 막혔을 때

- 줄 번호가 안 보이면 편집기 설정에서 줄 번호 표시를 켭니다. (VS Code: 설정에서 `line numbers`, IntelliJ: Settings → Editor → General → Appearance → Show line numbers)
- 파일 첫 줄의 `package chapter03;`은 클래스 선언보다 **위**에 있습니다. 1-3에서 세는 중괄호 범위에는 들어가지 않습니다.
- 1-4에서 자리가 3개보다 많이 세어졌다면, `package` 줄까지 셌을 수 있습니다. 세미콜론으로 끝나는 줄은 모두 4개이고 그중 **중괄호 안쪽에 있는 3개**만 값의 자리입니다.
- 1-5의 검색 결과가 0건이라 당황했다면 정상입니다. **없다는 것을 확인하는 것**이 이 단계의 목적입니다.

## 제출 결과물

- 1-3의 여는 중괄호 · 닫는 중괄호 줄 번호
- 1-4의 값의 자리 표 (3행 모두 채운 것)
- 1-6의 입력 → 처리 → 출력 3문장과 "이 파일만으로 실행되지 않는 이유" 한 줄
