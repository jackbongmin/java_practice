# 1일차 2교시 실습 — 개발 환경과 실행 구조

## 이번 시간에 할 일

- 작성한 `.java` 파일이 곧바로 실행되는 게 아니라 **컴파일 단계**를 거친다는 것을 파일 수준에서 확인합니다.
- 폴더 이름 · `package` 선언 · 파일명 · 클래스명이 **한 묶음으로 지켜져야 하는 규칙**임을 오류로 직접 겪습니다.

## 실습 파일

- `chapter02/PrintOnePlusOne.java`
- 실습 폴더 구조 자체: `02_lecture/01_java/practice/01_01/` 아래의 `chapter02/`, `chapter03/`

> 이번 미션은 일부러 **컴파일 오류를 내 보는** 것이 목적입니다. 오류 메시지를 기록한 뒤에는 반드시 원래 코드로 되돌리세요.

## 미션

### 2-1. 실행하면 무엇이 새로 생기는지 찾는다
`PrintOnePlusOne`을 실행합니다. 그 다음 IDE의 출력 폴더(예: `out/`, `bin/`, `target/classes/`)에서 새로 생긴 **`.class` 파일**을 찾아 경로를 적습니다.
→ 이 파일이 원래의 `.java` 파일과 무엇이 다른지 한 줄로 씁니다. (사람이 읽는 것 / 기계가 읽는 것)

### 2-2. package 선언과 폴더 이름을 대조한다
`chapter02/`와 `chapter03/` 안에서 아무 파일이나 **세 개**를 열어, 첫 줄의 `package ...;` 선언이 실제 폴더 이름과 일치하는지 확인하고 표로 적습니다.

### 2-3. package 선언을 어긋나게 해 본다
`chapter02/PrintOnePlusOne.java`의 첫 줄을

```java
package chapter03;   // 파일은 chapter02 폴더에 그대로 둔 채
```

로 바꾸고 **컴파일한 다음 실행까지** 해 봅니다.

| 단계 | 명령 | 결과 (오류면 메시지 첫 줄) |
|---|---|---|
| 컴파일 | `javac -d out chapter02/PrintOnePlusOne.java` | |
| 실행 | `java -cp out chapter02.PrintOnePlusOne` | |

- 만들어진 `.class` 파일은 `out/` 아래 **어느 폴더**에 있습니까? → __________
- 그 위치를 정한 것은 파일이 놓인 폴더입니까, `package` 줄입니까? → __________

기록한 뒤 되돌립니다.

### 2-4. 클래스명과 파일명을 어긋나게 해 본다
같은 파일에서 **파일명은 그대로 두고** 클래스 이름만 바꿉니다.

```java
public class Print1 {
```

컴파일해서 나온 오류 메시지를 기록한 뒤 되돌립니다.

### 2-5. 언제 났는지 확인한다
2-3과 2-4의 오류가 각각 **어느 단계**에서 났는지 판정합니다. **둘은 다릅니다.**

| | 컴파일 단계에서 막혔나 | 실행 단계에서 막혔나 |
|---|---|---|
| 2-3 (package 어긋남) | | |
| 2-4 (클래스명 어긋남) | | |

- 한쪽은 컴파일러가 잡아 주고 다른 쪽은 잡아 주지 않습니다. **왜 그런지** 한 문장으로 → __________
  (힌트: `javac`는 `package` 줄을 「틀렸다」고 볼 수 있습니까, 아니면 「그렇다니 그런가 보다」 할 수밖에 없습니까?)

## 스스로 점검

- JDK · JVM · IDE가 각각 어느 단계를 담당하는지 자기 말로 설명할 수 있다.
- 2-3은 실행 단계, 2-4는 컴파일 단계에서 막힌다는 것을 직접 실행해 확인했다.
- 파일을 다른 패키지로 옮기려면 무엇을 **함께** 바꿔야 하는지 안다.

## 막혔을 때

- 오류 메시지에 파일 경로와 줄 번호가 함께 나옵니다. 메시지의 **첫 줄**부터 읽으세요.
- 되돌린 뒤에도 오류가 남아 있으면, IDE에서 프로젝트를 다시 빌드(Rebuild)합니다.

## 제출 결과물

- 새로 생성된 `.class` 파일 경로
- 2-3의 실행 단계 오류 메시지 1건 + 2-4의 컴파일 오류 메시지 1건 (어느 단계인지 함께 적기)
- "소스 → 바이트코드 → 실행" 각 단계와 그 담당자를 정리한 3문장
