# 1일차 3교시 실습 — 출력과 기본 메서드 호출

## 이번 시간에 할 일

- `main()`이 **실행의 시작점**이고, 인스턴스 메서드는 **호출해야만** 실행된다는 것을 확인합니다.
- 같은 값을 `print` · `println` · `printf`로 출력해 차이를 관찰합니다.
- `+`가 숫자를 만나면 덧셈, 문자열을 만나면 연결이 된다는 것을 실행 결과로 확인합니다.

## 실습 파일

- `chapter02/PrintOnePlusOne.java`
- `chapter02/JavaInput.java`
- `chapter02/JavaInputTest.java`

## 미션

### 3-1. 호출을 지우면 어떻게 되는가
`PrintOnePlusOne`을 실행해 결과를 확인합니다. 그 다음 `main()` 안의

```java
printOnePlusOne.print(); // print() 메소드 호출
```

이 **한 줄만** 주석 처리하고 다시 실행합니다. 출력이 어떻게 달라지는지 기록합니다. (출력이 아무것도 없는 것도 결과입니다.) 확인 후 주석을 풉니다.

### 3-2. `+`의 두 얼굴
`print()` 메서드 안의 `System.out.println(1 + 1);` 아래에 다음 줄을 추가합니다.

```java
System.out.println("1" + "1");
```

**실행 전에** 두 줄이 각각 무엇을 출력할지 예측해 적고, 실행해 비교합니다.

이어서 아래 네 줄을 차례로 넣어 보며 사칙연산 결과를 관찰합니다. 특히 **정수 나눗셈**의 결과에 주목하세요.

```java
System.out.println(7 + 2);
System.out.println(7 - 2);
System.out.println(7 * 2);
System.out.println(7 / 2);   // 3.5가 나오는가?
```

마지막으로 다음 두 줄의 결과를 **예측한 뒤** 실행해 비교합니다. 괄호 하나가 왜 결과를 바꾸는지 적습니다.

```java
System.out.println("결과: " + 10 + 20);
System.out.println("결과: " + (10 + 20));
```

### 3-3. println 대신 print
3-2에서 만든 출력 문장들을 `println` 대신 `print`로 바꿔 실행합니다. 콘솔에서 줄바꿈이 어떻게 달라지는지 캡처해 둡니다. 확인 후 되돌립니다.

### 3-4. 인스턴스 메서드를 클래스명으로 부르면
`JavaInputTest`를 열어 `JavaInput`의 `readAChar()`가 **어떻게** 호출되는지 확인합니다. 그 다음

```java
javaInput.readAChar();
```

를

```java
JavaInput.readAChar();   // 인스턴스 대신 클래스 이름으로 호출
```

로 바꿔 컴파일하고, 오류 메시지를 기록한 뒤 되돌립니다.

### 3-5. 문자 하나를 넣어 본다
`JavaInputTest`를 실행해 문자 `A` 하나를 입력하고 출력값을 기록합니다. (예상과 다른 값이 나올 수 있습니다. 그 이유는 5교시에 확인합니다.)

## 스스로 점검

- 3-1에서 출력이 사라진 이유를 "메서드는 정의만으로 실행되지 않는다"로 설명할 수 있다.
- 3-2에서 `2`와 `11`이 갈린 이유를 **타입**으로 설명할 수 있다.
- 3-4의 오류가 `static` 메서드와 인스턴스 메서드의 차이 때문임을 안다.

## 막혔을 때

- 프로그램이 멈춘 것처럼 보이면 `Scanner`나 `InputStreamReader`가 **입력을 기다리는 중**입니다. 콘솔에 값을 입력하고 엔터를 누르세요.

## 제출 결과물

- 3-1 ~ 3-3의 실행 결과 캡처 (출력이 없는 경우도 포함)
- 3-4의 컴파일 오류 메시지 원문
- `print` / `println` / `printf`를 각각 언제 쓸지 정리한 3줄 메모
